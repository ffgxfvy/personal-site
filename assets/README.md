# 简历 PDF 放这里

站点首页的「简历 PDF」按钮指向 `assets/resume.pdf`，**这个文件需要你自己放进来**。

## 放之前必须做的事

源文件在 `D:\桌面\实习\简历.pdf`。导出前请检查：

- [ ] **删除手机号**（这是最重要的一条 —— PDF 会被搜索引擎抓取）
- [ ] 删除学号
- [ ] 删除身份证号 / 家庭住址
- [ ] 确认没有云平台 token、内网地址
- [ ] 照片可保留（求职场景需要）

## 建议

- 文件名保持 `resume.pdf`（站点里写死了这个路径）
- 同时导出一份**英文版** `resume-en.pdf`，投外企或海外岗位时用
- 如果不想公开简历，把 `index.html` 里「简历 PDF」那个 `<a>` 标签删掉即可，
  换成"简历可邮件索取"的文字
